# Tutorial downloads

The learner pack contains runnable scripts, exported slides, handouts, a
workbook and the command extension. The manifest records file hashes. Guest
disk images are downloaded separately.

- [Combined presentation PDF](/tutorials/atc26/femu-atc26-presentation.pdf)
- [Flattened handout PDF](/tutorials/atc26/femu-atc26-handout.pdf)
- [Printable workbook PDF](/tutorials/atc26/femu-atc26-workbook.pdf)
- [Learner pack](/tutorials/atc26/femu-atc26-learner-pack.tar.gz)
- [SHA-256 checksum](/tutorials/atc26/femu-atc26-learner-pack.sha256)
- [File manifest](/tutorials/atc26/manifest.json)

Verify the checksum before extracting. Use the canonical
[guest-image guide](/manual/getting-started/guest-image) to prepare the separate
image. Image identity and tool versions must be recorded for your own run.

Video recordings are not available yet.
