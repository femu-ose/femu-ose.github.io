# femu-ose organisation logo

The FEMU site mark (navy tile, white F, cyan flash cells) with the cells
stepping up and outward: one emulator growing into a community-run ecosystem.
It keeps the website's colours, `#12364a`, `#f5fbff` and `#69c7dc`.

| File | Use |
| --- | --- |
| `femu-ose-avatar-500.png`, `femu-ose-avatar-1024.png` | GitHub organisation avatar (full bleed; GitHub rounds the corners) |
| `femu-ose-avatar.svg` | Source of the avatar |
| `femu-ose-logo.svg`, `femu-ose-logo-512.png` | The mark on its own tile, for READMEs and slides |
| `femu-ose-lockup.svg`, `femu-ose-lockup.png` | Mark with "FEMU, open-source ecosystem", for banners |
| `candidates/` | The other designs considered and the site mark they start from |

Rejected candidates: `a-cells` was too close to the site mark to identify the
organisation; `b-network` reads as the common "share" icon at small sizes.

To set the avatar: github.com/organizations/femu-ose/settings/profile,
"Profile picture", upload `femu-ose-avatar-1024.png`.
